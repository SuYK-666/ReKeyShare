# Shared Package V2

下载响应通过 `SharedPackageV2` 提供可验证元数据：

| Field | Purpose |
| --- | --- |
| `packageVersion` | Outer format, fixed to `v2` |
| `manifestFormatVersion` | Integrity manifest version, currently `2.0` |
| `minVerifierVersion` | Minimum accepted verifier, currently `2.0` |
| `schemeId`, `parameterSpec`, `proofStatus` | Explicit cryptographic boundary |
| `contentKeyVersion` | Key-version binding |
| `ciphertextHash`, `aadHash`, `capsuleHash` | Cryptographic material integrity |
| `grantPolicyHash`, `grantContextHash` | Authorization/context binding |
| `manifestHash` | Digest over versioned manifest fields |

`PackageVerifier` fails closed on an unknown package version, a downgraded
manifest version or verifier requirement, expiry, manifest tamper, or key
version mismatch. Future major formats require a separate verifier; minor
extensions must not remove or reinterpret fields covered by `manifestHash`.
